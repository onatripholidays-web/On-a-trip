V26 is the master SEO framework for On A Trip Holidays. It combines technical SEO, on-page SEO, keyword architecture, content clusters, local SEO, authority building, performance monitoring, competitor intelligence and Search Console-driven optimization.

## Important
V26 is designed to work with the existing website. Preserve working V21 redirects, robots.txt, sitemap.xml, canonical URLs and public landing pages unless an audit proves a change is necessary.

Search demand → keyword ownership → correct landing page → useful content → internal links → crawl/index → ranking → click → enquiry → booking → measurement → optimization.
