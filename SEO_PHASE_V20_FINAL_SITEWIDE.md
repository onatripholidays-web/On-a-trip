# On A Trip Holidays — V20 Sitewide SEO Finalisation

V20 focuses on discoverability and indexability of the existing destination landing pages rather than mass-producing thin pages.

## Changes
- Added `destinations-from-hyderabad.html` as a crawlable hub linking the 22 core Hyderabad destination landing pages.
- Upgraded the 22 core landing pages with consistent title/description/canonical/robots/Open Graph/Twitter metadata.
- Added BreadcrumbList structured data where missing.
- Improved destination image alt text.
- Added discovery links from the homepage, Packages and Pilgrimage hubs.
- Removed the unrelated Maldives-to-Char-Dham redirect.
- Added noindex response headers for `/admin.html` and `/crm.html`.
- Removed redirected legacy Hyderabad URLs from the sitemap and added `lastmod` to pages materially updated in V20.
- Preserved existing internal links, V15/V16/V17/V18/V19 content, photography, FAQ/schema and accurate legacy redirects.

## Important
Google decides which pages to index and rank. V20 improves crawlability, relevance signals and user experience but does not guarantee a ranking or immediate indexing. Avoid creating large numbers of near-duplicate city/destination pages; each indexed landing page should remain genuinely useful and destination-specific.
