# V26 Master SEO Checklist

## 1. Technical SEO
- [ ] HTTPS works on every public URL
- [ ] One preferred hostname
- [ ] Homepage canonical is correct
- [ ] Every indexable page has a self-referencing canonical where appropriate
- [ ] robots.txt is accessible and valid
- [ ] sitemap.xml contains only canonical/indexable public URLs
- [ ] Important pages return HTTP 200
- [ ] Broken internal links removed
- [ ] Redirect chains minimized
- [ ] Legacy URLs redirect to the most relevant current page
- [ ] Admin/CRM/private paths are not indexed
- [ ] Custom 404 is noindex
- [ ] No accidental noindex on commercial pages
- [ ] Mobile layout works
- [ ] Core Web Vitals monitored

## 2. On-page SEO
- [ ] One clear H1 per primary page
- [ ] Unique title
- [ ] Useful meta description
- [ ] Search intent matches page purpose
- [ ] Natural primary keyword usage
- [ ] Related entities and destinations covered
- [ ] Images have meaningful ALT text
- [ ] Internal links use descriptive anchors
- [ ] No keyword stuffing
- [ ] No thin doorway pages

## 3. Structured data
- [ ] Organization/TravelAgency data is accurate
- [ ] LocalBusiness data is accurate where appropriate
- [ ] BreadcrumbList matches visible breadcrumbs
- [ ] FAQ schema only where FAQs are visible and genuinely useful
- [ ] No fake ratings/reviews/offers
- [ ] Schema URLs match canonical URLs

## 4. Local SEO
- [ ] Google Business Profile is complete
- [ ] NAP is consistent
- [ ] Hyderabad location signals are accurate
- [ ] Telangana and Andhra Pradesh service area is clear
- [ ] Genuine customer reviews are encouraged
- [ ] Business photos and updates are maintained

## 5. Authority
- [ ] Relevant travel citations
- [ ] Relevant local/Hyderabad publications
- [ ] Telugu media opportunities
- [ ] Travel partnerships
- [ ] Quality backlinks
- [ ] Avoid purchased/spam backlink schemes

## 6. Measurement
- [ ] Google Search Console verified
- [ ] GA4 configured
- [ ] Organic clicks tracked
- [ ] Impressions tracked
- [ ] CTR tracked
- [ ] Queries tracked
- [ ] Pages tracked
- [ ] Conversions/enquiries tracked
- [ ] Rankings reviewed periodically
- [ ] Competitor gaps reviewed periodically
