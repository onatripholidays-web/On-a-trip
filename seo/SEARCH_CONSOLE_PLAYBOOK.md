# V26 Google Search Console Playbook

## Weekly
Check:
- queries gaining impressions
- queries gaining clicks
- pages gaining visibility
- pages losing clicks
- indexing issues
- sitemap status
- Core Web Vitals issues

## Opportunity pattern
If a page has:
- high impressions
- low CTR

Review title and meta description.

If a page has:
- impressions
- position 8–20
- relevant intent

Improve content depth, internal links, title/H1 alignment and authority.

If a page has:
- no impressions

Check indexability, canonical, sitemap discovery, internal links and whether the topic has real search demand.

## Important
Search Console is the source of truth for how Google is actually surfacing the verified site. Third-party tools estimate data and should be treated as supporting evidence.
