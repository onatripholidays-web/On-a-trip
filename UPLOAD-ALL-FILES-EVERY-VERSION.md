# Upload the whole website at once — recommended workflow

If GitHub's browser uploader will not accept all website files together, do **not** upload 187 files manually.

## Best one-time setup: GitHub Desktop

1. Install GitHub Desktop.
2. Clone `onatripholidays-web/On-a-trip` to your computer.
3. Keep that folder as your permanent website working folder.
4. For every new On A Trip version, download the ZIP generated by ChatGPT.
5. Extract the ZIP and copy the contents of `On-a-trip-main` over the cloned repository folder.
6. Open GitHub Desktop. It will automatically show all changed/added/deleted files.
7. Enter a commit message such as `Deploy V18 SEO update`.
8. Click **Commit to main**.
9. Click **Push origin**.

This uploads the entire set of changes in one Git operation. You do not need to select 187 files in the GitHub browser.

## Even easier after the first setup

For V19, V20, etc.:

**Download ZIP → Extract/overwrite the cloned folder → GitHub Desktop → Commit → Push.**

## Important
Do not delete the `.git` folder inside your cloned repository. Only replace the website files.

If Vercel is connected to the GitHub `main` branch, the push should trigger the normal deployment automatically.
